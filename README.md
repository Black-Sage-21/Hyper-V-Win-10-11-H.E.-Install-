# Hyper-V-Win-10-11-H.E.-Install-
Hyper-V Win 10/11 Home Edition Install 
Enabling Hyper-V on Windows 10/11 Home

This guide explains how to attempt to enable Hyper-V on Windows 10/11 Home edition using either a Batch (.bat) file or PowerShell.

It covers:

Creating and running the required commands as Administrator

Restarting Windows after making the changes

Verifying that Hyper-V has been installed successfully

Troubleshooting common issues

Enabling hardware virtualization in BIOS/UEFI

Understanding the limitations of Windows Home edition

Quick Start

The full instructions are available in the included Hyper-V text file.

Alternatively, you can simply download the .bat file and run it as Administrator to attempt the installation.

Important: Right-click the .bat file and select Run as administrator.

Important Notes

⚠️ Hyper-V is officially supported only on Windows Pro, Enterprise, and Education editions.

Enabling Hyper-V on Windows 10/11 Home using these methods is unofficial and may not work on every Windows version or build.

Your computer must also support hardware virtualization, and virtualization must be enabled in your BIOS/UEFI settings. Depending on your system, this may appear as:

Intel VT-x / Intel Virtualization Technology

AMD-V / SVM Mode

If Hyper-V does not appear after installation, verify that virtualization is enabled in BIOS/UEFI and that your Windows build supports the required Hyper-V components.

⚠️ Compatibility Disclaimer

Because Windows Home does not officially include Hyper-V, results may vary depending on your Windows version, build, hardware, and system configuration.

Use these methods at your own discretion, and create a backup or restore point before making significant system changes.
