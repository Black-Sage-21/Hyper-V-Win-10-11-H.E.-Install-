Enable Hyper-V Windows 10/11 Home Edition 

Below is a beginner-friendly, step-by-step guide for Windows 10/11 Home.

> **Important:** Hyper-V is officially included with Windows Pro, Enterprise, and Education editions. The `.bat` method attempts to enable the Hyper-V packages/features on Home editions, but it is not an officially supported Microsoft configuration. Make sure virtualization is enabled in your PC's BIOS/UEFI first.

## Method 1 — Using the `.bat` file

### Step 1: Create the batch file

1. Open **Notepad**.
2. Copy and paste the following code into Notepad:

```
pushd "%~dp0"
dir /b %SystemRoot%\servicing\Packages\*Hyper-V*.mum >hyper-v.txt
for /f %%i in ('findstr /i . hyper-v.txt 2^>nul') do dism /online /norestart /add-package:"%SystemRoot%\servicing\Packages\%%i"
del hyper-v.txt
Dism /online /enable-feature /featurename:Microsoft-Hyper-V -All /LimitAccess /ALL
pause
```

3. In Notepad, click **File → Save As**.
4. Choose somewhere easy to find, such as your **Desktop**.
5. In **File name**, enter:

```
enable-hyper-v.bat
```

6. For **Save as type**, select:

```
All Files (*.*)
```

7. Click **Save**.

### Step 2: Make sure it is actually a `.bat` file

On your Desktop, you should now see something like:

**enable-hyper-v.bat**

If it appears as:

**enable-hyper-v.bat.txt**

Then Windows saved it as a text file rather than a batch file.

To check file extensions:

1. Open **File Explorer**.
2. Click **View**.
3. Select **Show → File name extensions**.
4. Verify the file ends in `.bat`.

### Step 3: Run the batch file as Administrator

1. Right-click **enable-hyper-v.bat**.
2. Select **Run as administrator**.
3. If Windows displays a **User Account Control** prompt, select **Yes**.
4. A Command Prompt window will open.
5. The script will search for the Hyper-V packages and use **DISM** to add them.
6. Wait for the process to finish.

Do **not** close the Command Prompt while the commands are running.

### Step 4: Restart Windows

When the script finishes, restart your computer.

You can use:

**Start → Power → Restart**

A restart is important because Windows needs to load the Hyper-V components.

### Step 5: Check whether Hyper-V is enabled

After restarting:

1. Press **Windows + R**.
2. Type:optionalfeatures
3. Press **Enter**.
4. Look for **Hyper-V**.

If the feature was successfully enabled, you may see:

- **Hyper-V**
- Hyper-V Management Tools
- Hyper-V Platform

You can also search the Start menu for:

**Hyper-V Manager**

If **Hyper-V Manager** opens, the installation was successful.

# Method 2 — Using PowerShell

You can also try Microsoft's Windows optional-feature mechanism directly.

### Step 1: Open PowerShell as Administrator

1. Click Start
2. Search for: "PowerShell"
3. Right-click **Windows PowerShell**.
4. Select **Run as administrator**.
5. Select **Yes** if Windows asks for permission.

### Step 2: Run the command

Paste this command into the Administrator PowerShell window:

```

Enable-WindowsOptionalFeature -Online -FeatureName Microsoft-Hyper-V -All -NoRestart


```

 Press **Enter**

 Windows will attempt to enable Hyper-V and its required components.

### Step 3: Restart the computer

When the command finishes, restart Windows:

```

Start → Power → Restart

```

### Step 4: Verify Hyper-V

After restarting, press **Windows + R**, enter:

```

optionalfeatures

```

and press **Enter**.

Alternatively, search for **Hyper-V Manager** from the Start menu.

## If you get an error

A few things can prevent Hyper-V from working even if the commands run successfully.

### 1\. Hardware virtualization must be enabled

Your processor and firmware need to support virtualization.

Depending on your computer, the BIOS/UEFI setting may be called:

- **Intel Virtualization Technology (VT-x)**
- **Intel VT**
- **AMD-V**
- **SVM Mode**
- **Virtualization Technology**

You can check Windows first by opening **Task Manager → Performance → CPU** and looking for:

**Virtualization: Enabled**

If it says **Disabled**, you'll need to enable virtualization in your BIOS/UEFI.

### 2\. Check your Windows edition

Press **Windows + R**, type:

```

winver

```

and press **Enter**.

You can also go to:

**Settings → System → About**

and look under **Windows specifications**.

### 3\. Home edition limitations

The important distinction is that **Hyper-V is not officially offered as a normal optional Windows feature on Windows Home**. The batch script you posted works by locating Hyper-V component packages already present in the Windows installation and attempting to install/enable them.

Because of that, the result can vary depending on the specific Windows build and component files present on the machine.

### Recommended order

If you're trying this on Windows 10/11 Home, I'd recommend:

1. **Check that CPU virtualization is enabled.**
2. **Create the `.bat` file** from Method 1.
3. **Run it as Administrator.**
4. **Wait for DISM to finish.**
5. **Restart Windows.**
6. **Check `optionalfeatures` and Hyper-V Manager.**
7. If that doesn't work, **try the PowerShell command**.
8. If Hyper-V still cannot be enabled, check the DISM error message rather than repeatedly running the script.

**One caution:** I would not recommend downloading a modified Windows ISO or random "Hyper-V enabler" packages from the internet. The commands above use Windows' own DISM/component servicing mechanisms.
